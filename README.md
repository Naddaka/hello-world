# Zadum

Настольное приложение для macOS: визуальные доски для идей, ресёрча и
видеопродакшна. Свободная раскладка карточек, вложенные доски,
форматированный текст — всё хранится локально.

Документы проекта:
- `docs/product/plan.md` — план продукта и этапы;
- `docs/reference/milanote-feature-inventory.md` — функции референса.

## Что уже работает (этап 0)

- Главная доска и вложенные доски любой глубины, хлебные крошки,
  навигация ⌘[ / ⌘] / ⌘U.
- Бесконечный холст: прокрутка двумя пальцами или колесом, пробел +
  перетаскивание, масштаб щипком или ⌘ + колесо, ⌘+ / ⌘− / ⌘0, Z —
  показать всё.
- Заметки: двойной клик по пустому месту; стили (⌘⇧1, ⌘⇧2, ⌘⇧0, ⌘⇧9),
  жирный, курсив, подчёркнутый, зачёркнутый (⌘⇧X), выделение (⌘J),
  списки (⌘⇧U, ⌘⇧O), чекбоксы, цитата, код, по центру (⌘\), ссылки (⌘K),
  markdown в начале строки (`# `, `. `, `- `, `1. `, `[ ] `, `> `),
  цвет карточки, ширина; ⌘Enter — следующая заметка.
- Выделение кликом, Shift-кликом и рамкой; перетаскивание по сетке,
  ⌥ + перетаскивание — копия, стрелки (Shift — шаг больше), слои
  ⌘⇧↑ / ⌘⇧↓, закрепление, контекстное меню.
- Перенос карточек в доску — бросить на плитку доски или на хлебную крошку.
- Отмена и повтор (⌘Z / ⌘⇧Z) для всех действий; автосохранение.
- Светлая и тёмная тема (⌘⇧D).

## Разработка

Нужны Node.js 22 и Rust (stable).

```bash
npm install
```

Запустить приложение для Mac в режиме разработки:

```bash
npm run tauri dev
```

Собрать `.app` и `.dmg`:

```bash
npm run tauri build
```

Проверки:

```bash
npm run typecheck
```

```bash
npm test
```

```bash
npm run build && npm run e2e
```

`npm run dev` открывает интерфейс в браузере (данные — в IndexedDB браузера);
в приложении Tauri данные лежат в SQLite-файле `zadum.db` в папке
`~/Library/Application Support/io.zadum.app`.

Каждый пуш собирает `.dmg` в GitHub Actions (workflow «Build», артефакт
`Zadum-macOS`). Сборка не подписана: при первом запуске откройте
приложение через правый клик → «Открыть».
