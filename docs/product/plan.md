# План продукта

Рабочее название не выбрано (варианты — в разделе 7).

## 1. Цель

Настольное приложение для macOS, в котором можно организовывать
информацию точно так же, как в Milanote: вложенные доски, свободная
раскладка карточек, форматированный текст, встраивание онлайн-медиа и
ссылок. Основной сценарий — видеопродакшн (идеи, ресёрч, мудборды,
сценарии, раскадровки, планирование съёмок), плюс любые задачи, где
информацию нужно аккуратно разложить визуально.

Полный перечень функций референса: `docs/reference/milanote-feature-inventory.md`.

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Платформа | macOS, приложение на **Tauri 2** |
| Совместная работа, аккаунты, облако | **Отложено.** Модель данных проектируем так, чтобы добавить позже |
| Хранение | Локально: база + папка с файлами на диске пользователя |
| Онлайн-медиа | Встраивание (YouTube, Vimeo, Spotify, карты и т.д.) работает онлайн; превью и метаданные ссылок сохраняются локально |
| Импорт из Milanote | **Обязателен**, весь контент с сохранением структуры и раскладки |
| Дизайн | Свой, функции и поведение — как в референсе |

## 3. Архитектура (предложение)

- **Оболочка:** Tauri 2 (Rust) — окна, меню macOS, файловая система,
  уведомления, хранилище, сетевые запросы без ограничений CORS (превью
  ссылок, импорт).
- **Интерфейс:** React + TypeScript.
- **Холст:** DOM-элементы с CSS-трансформациями (как у референса) —
  нативный текст, выделение, доступность; привязка к сетке.
- **Текст:** TipTap/ProseMirror (MIT) — тот же класс редактора, что у
  референса; markdown-автозамены, стили, списки, ссылки.
- **Таблицы:** собственный движок ячеек + formula.js (MIT) — покрывает
  набор из 355 функций референса.
- **Данные:** SQLite (элементы, доски, метки, история) + файлы вложений
  в библиотеке приложения. Каждый элемент — стабильный ID, тип,
  родитель, зона (холст / unsorted / корзина / прикреплён), позиция в
  единицах сетки, содержимое. Изменения пишутся как операции — основа для
  undo/redo, а позже для синхронизации и совместной работы.
- **Сборка:** разработка и тесты интерфейса — в облаке (браузер);
  сборка `.app`/`.dmg` под macOS — через GitHub Actions (macOS runner)
  или локально на Mac.

## 4. Импорт из Milanote

Штатный экспорт Milanote (PDF/PNG/Word/Markdown/ZIP по одной доске)
теряет раскладку и структуру, поэтому для полного переноса он не подходит.

Веб-клиент Milanote загружает данные через REST API (`users/me/app-init`,
`boards`, `elements?ids=…&loadAncestors=…` → элементы, комментарии,
метки; вложения — через медиасервер). План импорта:

1. В приложении — «Импорт из Milanote»: открывается окно входа в
   Milanote, пользователь входит **сам** (пароль приложению не передаётся).
2. Импортёр от имени этой сессии читает только данные пользователя:
   домашнюю доску, затем рекурсивно все вложенные доски и их элементы.
3. Скачивает все вложения (изображения, файлы, видео, аудио) в
   локальную библиотеку.
4. Переводит элементы в нашу модель 1:1 (тип, позиция, размер, цвет,
   текст с форматированием, метки, линии, комментарии, задачи, таблицы).
5. Показывает отчёт: сколько досок/элементов/файлов перенесено, что не
   удалось.

Первым шагом — разведка на реальном аккаунте: снять образец ответов API
по нескольким доскам, чтобы точно зафиксировать формат каждого типа
элемента до проектирования модели данных.

Замечание: это перенос собственных данных пользователя; автоматический
доступ к API может противоречить условиям Milanote — импорт
запускается вручную самим пользователем, без массовых запросов.

## 5. Инструменты для видеопродакшна

### 5.1 Редактор сценариев (приоритет)
- Форматы: **голливудский** (US Letter, Courier 12 pt, стандартные поля:
  1,5" слева, 1" справа/сверху/снизу; ≈1 страница = 1 минута),
  **европейский A4**, **русский** формат, **двухколоночный AV-сценарий**
  (видео | аудио — для рекламы, документального кино, YouTube),
  театральная пьеса.
- Элементы: заголовок сцены (INT./EXT., место, время), действие,
  персонаж, ремарка, реплика, переход, титр, двойной диалог. Tab/Enter
  переключают элементы, как в профессиональных редакторах; автодополнение
  персонажей и локаций.
- Титульный лист, нумерация сцен, (MORE)/(CONT'D) на разрывах страниц,
  хронометраж по страницам.
- Импорт/экспорт: **Fountain** (открытый текстовый формат сценариев),
  **Final Draft (.fdx)**, PDF с точной вёрсткой, Word.
- Режим ревизий (цветные страницы, звёздочки изменённых строк).
- Сценарий живёт на доске как карточка-документ; сцены можно «вытянуть»
  на доску карточками.

### 5.2 Связанные инструменты (идеи)
- **Раскадровка:** карточки-кадры с изображением/скетчем, номером сцены и
  кадра, крупностью, ракурсом, движением камеры, объективом,
  длительностью; рамки форматов кадра (16:9, 2.39:1, 4:3, 9:16, 1:1);
  автосоздание доски-раскадровки из сцен сценария.
- **Shot list:** таблица-шаблон (сцена, кадр, крупность, ракурс,
  движение, оптика, оборудование, хронометраж) с экспортом в PDF/CSV.
- **Разбор сценария (breakdown):** пометки реквизита, актёров, костюмов,
  локаций в тексте (на базе меток) → сводные списки по сценам.
- **План съёмок / вызывной лист:** раскладка сцен по съёмочным дням
  (stripboard), генерация call sheet.
- **Ревью видео:** карточка локального видео с комментариями по таймкоду
  и маркерами; экспорт маркеров для Premiere/Resolve/Final Cut;
  стоп-кадр из видео → карточка-изображение.
- **Ссылки на файлы на диске:** карточка-ссылка на файл или папку
  проекта (без копирования тяжёлых исходников), «Показать в Finder».
- **Локации:** карточка с картой, фото, адресом, контактами, временем
  восхода/заката.
- **Команда и контакты:** карточки людей (роль, контакты, ставка).
- **Бюджет:** шаблон таблицы с формулами.
- **Телесуфлёр** из сценария или документа.
- **Шаблоны досок:** проект ролика, мудборд, ресёрч, препродакшн,
  постпродакшн-канбан.

## 7. Название

Кандидаты (перед выбором — проверить занятость имени и домена):

- **Frameboard** — кадр + доска; про видео и про визуальную организацию.
- **Mise** — от *mise-en-scène*: «всё на своих местах».
- **Takeboard** — дубль + доска.
- **Storyfield** — поле для истории, не только для видео.
- **Kadr** — коротко, по-русски, звучит и на английском.
- **Previz** — термин превизуализации в кино.
