# ИИ в Zadum

Zadum остаётся локальным приложением. ИИ подключается через собственный ключ API пользователя, и в сеть уходит только то, что пользователь сам отправил действием ИИ, и только выбранному провайдеру.

## Что нужно, чтобы начать

1. Ключ API Anthropic (Claude) — для всего, что связано с текстом и разбором картинок. Создаётся на console.anthropic.com → API Keys. Это отдельный счёт с оплатой по факту, не подписка Claude Pro.
2. Ключ API OpenAI — только для генерации кадров раскадровки. Создаётся на platform.openai.com → API keys. Для моделей картинок OpenAI может потребовать подтверждение организации.
3. Ключи вводятся в «ИИ → Настройки ИИ…» (значок ✦ в верхней панели). Там же выбираются модель Claude и тщательность.

## Как это устроено

- **Ключи хранятся в связке ключей macOS** и не попадают в веб-часть приложения. Запрос собирает официальный SDK Anthropic без учётных данных; Rust-часть добавляет ключ и отправляет запрос на `api.anthropic.com`. Разрешены только три адреса API: сообщения, подсчёт токенов и список моделей.
- **Приложение не подписано**, поэтому после каждого обновления macOS один раз спросит пароль для доступа к связке ключей. Нужно нажать «Разрешить всегда».
- **Ничего не меняется само.** Ответ показывается как предложение с галочками; в приложении что-то меняется только после нажатия кнопки «Добавить», «Создать» или «Сохранить». Принятое отменяется одним ⌘Z.
- **Перед отправкой видно, что уходит.** Первый запрос и любой большой запрос (больше 20 тысяч токенов) сначала показывают, что будет отправлено. Для больших — ещё точный объём и цену чтения: её считает сам API, бесплатно.
- **Цена видна после ответа**, рядом с названием модели. В настройках есть счётчик потраченного через Zadum. Это оценка; точные цифры — в консоли провайдера.
- **Если модель отказалась** отвечать на безобидный запрос (на медицинских темах такое возможно), API сам повторяет запрос на запасной модели, которую рекомендует Anthropic. Это включено для Opus 5.5, Sonnet 5.5 и Fable 5.2; у Haiku 5.5 запасной модели нет.

### Модели и цены

| Модель | Чтение / ответ, $ за млн токенов | Когда брать |
|---|---|---|
| Claude Opus 5.5 (по умолчанию) | 4 / 20 | Подходит для всего |
| Claude Sonnet 5.5 | 2 / 10 | Быстрее и вдвое дешевле |
| Claude Haiku 5.5 | 0,10 / 0,50 | Простые задачи: метки, описания картинок |
| Claude Fable 5.2 | 8 / 40 | Самая сильная: заметки редактора по большому сценарию |

Ориентир: полнометражный сценарий — около 50 тысяч токенов, его чтение на Opus 5.5 стоит около $0,20. Сценарий отправляется как кэшируемый материал: второе действие над тем же сценарием в течение пяти минут читает его в десять раз дешевле.

## Функции

### Сценарий (меню «ИИ» в редакторе сценария)

| Действие | Что делает | Что отправляется |
|---|---|---|
| Разбор сценария | Предлагает элементы по 13 категориям разбора. Показывает, в скольких сценах приложение находит каждый; то, чего в тексте нет, по умолчанию не отмечено | Сценарий целиком |
| Кадры для сцены | План съёмки сцены под курсором: крупность, ракурс, движение, оптика, длительность. Принятые кадры появляются в раскадровке сценария, shot list обновляется | Сценарий целиком |
| Заметки редактора | По сцене или по всему сценарию: структура, персонажи, диалоги, что править первым. Сохраняются документом на доске | Сценарий целиком |
| Варианты текста | Три варианта выделенного текста или строки под курсором. Замена — по кнопке, оригинал виден рядом | Сценарий целиком |
| Перевод RU↔EN | Отдельный сценарий в формате языка перевода (английский — голливудский). Оригинал не меняется. Длинный сценарий переводится частями | Сценарий целиком |

### Доски (значок ✦ в верхней панели)

| Действие | Что делает | Что отправляется |
|---|---|---|
| Спросить доски | Ответ на вопрос по всем доскам со ссылками на карточки. ИИ не получает доски целиком: он ищет по ним, как поиск, и читает только найденное | Вопрос и карточки, которые ИИ нашёл и прочитал |
| Сводка | Главное из доски или выделенных карточек — заметкой или документом | Текст этих карточек |
| Разложить по колонкам | Собирает заметки вне колонок в колонки по смыслу; названия можно поправить до принятия | Текст этих заметок |
| Предложить метки | 2–6 меток для карточек; существующие метки используются повторно | Текст карточек и названия меток |
| Описать картинки | Что на картинке и текст с неё. Сохраняется при картинке, и поиск начинает её находить. Есть и в меню картинки | Уменьшенные копии картинок (до 1568 пикселей) |

### Раскадровка и ревью

| Действие | Где | Что делает | Что отправляется |
|---|---|---|---|
| Сгенерировать кадр | Меню кадра: «ИИ: сгенерировать кадр…» | Картинка по описанию в одном из четырёх стилей, в пропорциях кадра. Сначала показывается, в кадр ставится по кнопке | В OpenAI: только описание |
| Список правок с ИИ | Ревью видео: «В задачи ▾» | Комментарии об одном и том же объединяются и формулируются как действия; список задач появляется рядом с видео | Комментарии с таймкодами; видео не отправляется |
| Список задач как есть | Там же | Каждый комментарий — задача с таймкодом. Работает без ИИ | Ничего |

## Чего нет

- **Расшифровка речи и субтитры.** Claude этого не делает; нужна отдельная модель распознавания речи. Не сделано.
- **GPT для текста.** OpenAI используется только для картинок.
- **ИИ в браузерной версии.** Ключи хранятся в связке ключей, поэтому ИИ работает только в приложении.

## Как это проверено

- Имитация API в тестах: модульные тесты (запросы, проверка ответов, агент с инструментами) и сквозные тесты в браузере для каждой функции (`e2e/stage7.mjs`, `stage8.mjs`, `stage9.mjs`).
- Rust-тесты: ключ добавляется только на стороне Rust, чужие учётные данные из запроса вырезаются, разрешены только нужные адреса API.
- **Не проверено с настоящими ключами.** В окружении разработки ключей API нет, поэтому настоящих запросов к Claude и OpenAI не было. Формы запросов взяты из документации; название модели картинок OpenAI (`gpt-image-2.5-sunburst`) взято со страницы их руководства и вынесено в настройки.

Что проверить первым делом с настоящим ключом:
1. Сохранение ключа и кнопку «Проверить» в настройках.
2. «Заметки редактора» по короткому сценарию: ответ должен печататься по мере готовности.
3. «Разбор сценария»: ответ в строгом формате.
4. «Спросить доски»: несколько шагов поиска подряд.
5. Генерацию кадра: если OpenAI ответит, что модели нет, поменять её название в настройках.
