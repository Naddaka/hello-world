# Референс: Milanote — инвентаризация функций

Документ фиксирует, что умеет референсное приложение, чтобы наша версия
повторила функциональность. Мы переносим **поведение**, а не код, графику,
тексты или бренд референса: реализация и визуальный дизайн — свои.

Статус: первый проход (статический анализ веб-клиента + справочный центр).
Пакет `Milanote.app` ещё не разобран — доступ к Mac пока не подключён.

## 1. Источники

| Источник | Что дал |
|---|---|
| Справочный центр (90 статей, 8 разделов) | Полный перечень функций с точки зрения пользователя, горячие клавиши, ограничения |
| Веб-клиент `app.milanote.com` (бандлы `main`/`vendor`, ~4,6 МБ) | Модель данных, типы элементов, список действий (Redux actions), используемые библиотеки |
| `Milanote.app` на Mac | **Ещё не получен.** Нужен для проверки, что десктоп = веб-клиент в оболочке, и для нативных деталей (меню, окна, deep links, офлайн-кэш) |

## 2. Как устроен референс

- **Десктоп-приложение — Electron-оболочка над веб-клиентом.** В бандле есть
  ветки `isElectron`, `ELECTRON_UPDATE_REQUIRED`, `ELECTRON_THEME_CHANGE`,
  `ELECTRON_APP_SLEEP/WAKE`, `ELECTRON_STORE_REHYDRATED`.
- **Стек клиента:** React + Redux + Immutable.js; редактор текста на
  TipTap/ProseMirror; совместное редактирование на Yjs; синхронизация через
  socket.io; drag-and-drop через react-dnd.
- **Всё на доске — «элементы»** одного из типов:

  | Тип | Что это |
  |---|---|
  | `BOARD` | Вложенная доска (как папка) |
  | `ALIAS` | Ярлык на доску |
  | `CARD` | Заметка (rich text) |
  | `DOCUMENT` | Длинный документ |
  | `COLUMN` | Колонка-контейнер |
  | `TASK_LIST` / `TASK` | Список задач / задача |
  | `IMAGE` | Изображение |
  | `FILE` | Файл (в т.ч. видео/аудио, загруженные с диска) |
  | `LINK` | Ссылка с превью (YouTube, Vimeo, Spotify, Google Maps…) |
  | `LINE` | Линия/стрелка между элементами |
  | `COMMENT_THREAD` | Ветка комментариев |
  | `SKETCH` | Карточка-рисунок |
  | `ANNOTATION` | Свободный рисунок поверх доски |
  | `COLOR_SWATCH` | Цветовой образец |
  | `TABLE` | Таблица с формулами |
  | `CLONE` | Синхронизированная копия заметки |

- **Расположение элемента** (`location.section`): `CANVAS` (на холсте),
  `INBOX` (панель «Unsorted»), `TRASH`, `DELETED`, `ATTACHED` (комментарий,
  прикреплённый к карточке), `QUICK_NOTES`.
- **Координаты в единицах сетки** (grid units, суффикс `GU`, напр.
  `colWidthsGU` у таблиц) — размеры и позиции привязаны к сетке.

## 3. Каталог функций

Пометки: **L** — работает полностью локально; **N** — нужен интернет
(встраивание внешних сервисов, поиск); **C** — облако/совместная работа
(требует решения, что делаем в локальной версии).

### 3.1 Доски и навигация
- **L** Домашняя доска (корень, приватная, не экспортируется, без шаблонов).
- **L** Вложенные доски любой глубины; создание перетаскиванием из панели
  инструментов; открытие двойным кликом.
- **L** Хлебные крошки сверху слева; перетаскивание элемента на крошку с
  удержанием 1 с открывает эту доску (перенос вверх по иерархии).
- **L** Перенос элемента на плитку доски (с удержанием — доска открывается).
- **L** Ярлык на доску (`ALIAS`): «Создать ярлык», или вставка URL доски в
  Link-карточку. Удаление оригинала ломает ярлык, удаление ярлыка — нет.
- **L** Иконка и фон доски (выбор иконки с поиском; фон доски).
- **L** Панель «Unsorted» у каждой доски (справа сверху): складывание идей,
  сюда попадает всё, что бросили на плитку доски; ⌘Enter при наборе —
  следующая заметка в Unsorted.
- **L** Навигация назад/вперёд/к родителю (⌘[ ⌘] ⌘U).
- **L** Поиск по текущей и всем доскам (⌘F), сортировка «последний
  просмотр / последнее изменение», поиск по меткам; недавние доски.

### 3.2 Холст
- **L** Бесконечный холст, панорамирование (пробел + перетаскивание),
  масштаб (⌘+/⌘-, ⌘+скролл, щипок), «вписать всё» (Z).
- **L** Привязка к сетке, перемещение стрелками (Shift — шаг больше).
- **L** Выделение рамкой, множественное выделение, выделить всё.
- **L** Порядок слоёв: на передний/задний план (⌘⇧↑/↓).
- **L** Блокировка позиции элемента (нельзя сдвинуть/удалить).
- **L** Дублирование: Alt+перетаскивание, «Дублировать», копировать/вставить
  (вставка в точку правого клика).
- **L** Контекстное меню на правом клике по любому элементу.
- **L** Undo/Redo для всех операций, включая метки.
- **L** Тёмная тема (⌘⇧D), масштаб интерфейса (⌘⇧< / ⌘⇧>).
- **L** Режим презентации: полный экран, скрыть комментарии, запрет
  редактирования, фокус на карточке по клику, зум; выход по Esc.
- **L** Подсказки («Show helpers»), меню горячих клавиш по «/».

### 3.3 Заметки и текст
- **L** Создание двойным кликом по холсту.
- **L** Форматирование: заголовки (2 уровня), обычный и мелкий текст, жирный,
  курсив, подчёркнутый, зачёркнутый, выделение (highlight), цвет текста,
  инлайн-код, блок кода, цитата, маркированный и нумерованный списки с
  отступами, чекбоксы, выравнивание по центру, гиперссылки.
- **L** Markdown-автозамены в начале строки: `# `, `. `/`- `, `1. `, `[ ] `, `> `.
- **L** Цвет карточки, прозрачный фон.
- **L** Синхронизированные копии заметок (`CLONE`): правка в одном месте
  меняет все копии; ссылка «есть другие копии» с переходом.
- **L** Длинная заметка → предложение конвертировать в Документ.
- **C** @упоминания (в локальной версии — без смысла, если нет других людей).

### 3.4 Документы
- **L** Отдельный редактор длинного текста с теми же стилями, что у заметки.
- **L** Отображение на доске иконкой или превью содержимого.
- **L** Экспорт документа: PDF, Word, Markdown, обычный текст.

### 3.5 Колонки
- **L** Контейнер для карточек: заголовок, счётчик карточек, сортировка
  перетаскиванием (с индикатором вставки), изменение размера, свернуть/
  развернуть, «Сгруппировать в колонку» для выделенных элементов,
  ⌘Enter — ещё одна колонка рядом. Колонка в колонке — нельзя; доски и
  документы в колонке — можно.

### 3.6 Задачи
- **L** Списки задач с заголовком, отступами (Tab/Shift+Tab), отметкой
  выполнения, удалением выполненных.
- **L** Срок и напоминание (дата + время) — в локальной версии через
  системные уведомления macOS.
- **C** Назначение задачи человеку, уведомления исполнителю.

### 3.7 Изображения
- **L** Загрузка перетаскиванием/через кнопку (несколько сразу → в Unsorted).
- **L** Изменение размера, подпись (выделить и печатать), цветная полоска.
- **L** Просмотр: скачать оригинал, кадрирование, поворот, рисование поверх
  (рисунок масштабируется с картинкой), блокировка позиции.
- **L/N** Удаление фона (в референсе — облачный сервис с лимитами; локально
  можно сделать через Vision framework macOS).
- **N** Поиск бесплатных фото (Pexels API).

### 3.8 Файлы, видео, аудио
- **L** Загрузка любых файлов (список форматов — справка «What kind of files
  can I upload?»): RAW/векторы, PDF, архивы, офисные, дизайн-файлы.
- **L** Видео и аудио из файла: плеер в карточке, автозапуск, зацикливание,
  громкость; обложка видео — перетащить картинку на карточку.
- **N** Встраивание видео (YouTube, Vimeo), аудио (Spotify, SoundCloud,
  YouTube Music, Bandcamp, Mixcloud, Apple Music).

### 3.9 Ссылки
- **N** Link-карточка: превью-картинка, URL, описание (подтягиваются с
  сайта; каждую часть можно скрыть/показать, картинку заменить своей).
- **N** Спец-встраивания: CodePen, Instagram/Dribbble/Flickr, Slideshare,
  Prezi, Airtable, Marvel.
- **N** Карта (только Google Maps).
- **L** Вставка URL доски → ярлык на доску.

### 3.10 Линии
- **L** Создание из «ручки» карточки или из панели инструментов; привязка к
  карточке или к точке на карточке; кривые (перетаскивание средней точки,
  двойной клик — сброс); подпись; цвет и толщина; Shift — строго по
  горизонтали/вертикали. Линии перемещаются вместе с карточками.

### 3.11 Рисование
- **L** Три режима: свободное рисование по доске, Sketch-карточка, рисование
  на изображении. Инструменты: перо (D), выделение (V), ластик (E), прошлый
  цвет (X), толщина 1–4; Shift+D — начать, Esc — сохранить.

### 3.12 Таблицы
- **L** Типы ячеек: авто, число, валюта, процент, чекбокс, текст, дата/время
  (авто-определение типа по вводу).
- **L** Формулы: 355 функций (математика, статистика, финансы, даты, текст,
  инженерные, комплексные числа) — набор соответствует open-source
  библиотеке formula.js; ввод по «=».
- **L** Добавление строк/колонок (угол, меню, ⌥+стрелка), ширина колонок,
  перенос строк/колонок, удаление, выравнивание, цвет ячеек, стили текста,
  цвет заголовка, выделение диапазона (Shift+стрелки), переход к последней
  ячейке (⌘+стрелка).

### 3.13 Цветовые образцы
- **L** Подбор цвета, сочетающегося с картинками на доске; автоматическое
  название цвета; ввод HEX вставкой; палитра с пипеткой (по картинкам доски);
  отображение HEX / RGB / HSL / без подписи; изменение размера.

### 3.14 Метки (labels)
- **L** Создание, назначение нескольким элементам, снятие, переименование
  (везде сразу), цвет, удаление; поиск по метке и счётчик использования.

### 3.15 Комментарии
- **L** Карточка-комментарий, ответы (ветка), реакции-эмодзи, правка своих
  комментариев, прикрепление комментария к карточке (двигается вместе с ней).
- **C** Уведомления участникам, комментарии на read-only досках.

### 3.16 Шаблоны
- **L** Выбор шаблона при открытии пустой доски (в референсе 100+ шаблонов —
  их контент принадлежит Milanote, свои шаблоны придётся сделать заново).
- **L** Свои шаблоны: «Сделать шаблоном» / «Вернуть в доску», создание доски
  из шаблона.

### 3.17 Корзина
- **L** Удалённое попадает в корзину (хранится 3 месяца), возврат
  перетаскиванием, «Очистить корзину».
- **C** Разделение «удалено мной / удалено другими».

### 3.18 Экспорт
- **L** Доска: PDF (стандарт/крупный), PNG, Word, Markdown, текст; ZIP со
  всеми файлами доски. Документ — отдельно (см. 3.4).

### 3.19 Совместная работа и аккаунт (облачное)
- **C** Приглашение редакторов по email / по ссылке, комментаторов,
  read-only ссылка без логина, пароль на доску, приветственное сообщение,
  embed-код, смена владельца, просмотр и удаление участников.
- **C** Работа в реальном времени, уведомления об изменениях, ежедневная
  сводка по email.
- **C** Аккаунты, вход (Google/Apple), тарифы Free/Pro, лимиты загрузки.
- **C** Веб-клипер для Chrome/Safari/Firefox, share-extension iOS,
  мобильные приложения.

## 5. Открытые вопросы

1. Что делаем с облачными функциями (раздел 3.19, пометки **C**) в
   локальной версии: убираем, откладываем или делаем по-своему
   (например, синхронизация через iCloud Drive, экспорт/импорт досок,
   локальная сеть).
2. Встраивания внешних сервисов (**N**): оставляем онлайн-встраивание или
   скачиваем медиа и метаданные ссылок в локальное хранилище (с учётом
   прав на чужой контент).
3. Технологии: нативное приложение (Swift/SwiftUI) или веб-технологии в
   оболочке (Tauri/Electron). Референс сам сделан на вебе; редактор
   текста (TipTap, MIT) и формулы (formula.js, MIT) доступны готовыми.
4. Импорт данных из Milanote (через его экспорт Markdown/ZIP) — нужен ли.
5. Название и визуальный стиль.

## 6. Что ещё проверить на Mac

- Разобрать `Milanote.app`: `Info.plist`, `app.asar` (локальный бандл или
  загрузка с сервера), меню приложения, окна, deep links (`milanote://`),
  офлайн-кэш, обработка drag-and-drop файлов из Finder.
- Пройти сценарии в живом приложении и записать точное поведение
  (анимации, привязка к сетке, размеры по умолчанию, реакции на клавиши).
